# Frameworks de Rédaction Professionnelle

## 1. La Méthode Shipley (Propositions Commerciales & Appels d'Offres)
**Focus** : Le client, ses problèmes, et comment vous les résolvez. 80% client, 20% vous.
**Structure de l'Executive Summary** :
1. **Winning Message** : "Pour permettre à [Client] d'atteindre [Objectif] d'ici [Date], notre approche déploie [Solution] garantissant [Bénéfice]."
2. **Hot Buttons** : Les 3 douleurs majeures du client.
3. **Solution** : Alignée sur les critères d'évaluation.
4. **Win Themes (FBP)** : Feature -> Benefit -> Proof. (Bénéfice d'abord).
5. **Past Performance** : Preuves chiffrées.
6. **Synthèse Financière / ROI**.

## 2. Le Memo Amazon "6-Pager" (Mémos & Décisions)
**Focus** : Ultra dense, factuel, pas de bla-bla.
**Structure** :
1. **Introduction & Context** : Le problème.
2. **Tenets** : Les principes directeurs (ex: "La sécurité prime").
3. **State of the Business** : Chiffres bruts, ce qui marche/ne marche pas.
4. **Options Stratégiques** : Comparaison avec compromis.
5. **Recommendation** : L'initiative choisie, budget.
6. **Exécution & Risques**.

## 3. La Pyramide de Minto SCQA (Audits & Stratégie)
**Focus** : BLUF (Bottom Line Up Front) - La conclusion dès le début.
**Introduction SCQA** :
- **Situation** : Contexte indiscutable.
- **Complication** : Le déclencheur du problème.
- **Question** : La question stratégique.
- **Answer** : La recommandation.
**Règle MECE** : Mutuellement Exclusif, Collectivement Exhaustif.
**Action Titles** : Les titres doivent être des phrases affirmatives concluantes, pas de titres descriptifs.

## 4. Copywriting Psychologist (Psychologie du Consommateur)
**Focus** : Persuasion scientifique, gestion de l'état émotionnel et niveau de conscience.
**L'Approche Mécanisme-Premier** :
1. **Niveau de Conscience (Awareness Stage)** :
   - *Inconscient* : Rédiger avec clarté, axé sur le problème (pas de jargon).
   - *Conscient du Problème* : Intensifier les conséquences et définir le problème précisément.
   - *Conscient de la Solution* : Comparer les approches et différencier.
   - *Conscient du Produit* : Mettre en avant la preuve, les détails, et traiter les objections.
2. **État Émotionnel** :
   - *Anxieux* : Emphase sur la sécurité, la certitude, l'accompagnement.
   - *Frustré* : Emphase sur le soulagement et la rapidité.
   - *Sceptique* : Emphase sur les preuves transparentes et mesurables.
3. **Placer la Preuve (Social Proof/Data)** : Toujours injecter la preuve *au moment exact* où le doute s'installe dans la lecture, et non juste à la fin.
4. **Friction** : L'appel à l'action (Call-to-Action) final doit être perçu comme la suite naturelle de l'intention du lecteur, sans friction.
